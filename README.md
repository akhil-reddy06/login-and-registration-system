# Login and Registration System

A simple and user-friendly **Login and Registration System** developed using **HTML, CSS, and JavaScript**. This project allows users to register an account and log in using their registered credentials.

Features

* User registration
* User login
* Form validation
* Password input
* User-friendly interface
* Responsive design
 Technologies Used

* HTML5
* CSS3
* JavaScript

How to Use

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter the required registration details.
5. Create an account.
6. Log in using your registered credentials.

Project Structure

```text
Login-Registration-System/
│
```
